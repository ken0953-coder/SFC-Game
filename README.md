# CYBER SPIN - SFC Racing Game

## 賽車遊戲 🏎️

超級任天堂 (SFC) 風格的頂視角賽車遊戲，靈感來自《新世紀GPX 閃電霹靂車》。

## 特色

- 🏁 頂視角賽車玩法
- ⚡ 能量系統 - 使用「超級衝刺」消耗能量
- 🏆 7位AI對手
- 🗺️ 迷你地圖導航
- 📊 HUD 即時顯示

## 操作方式

| 按鍵 | 功能 |
|------|------|
| ↑ / W | 加速 |
| ↓ / S | 煞車 |
| ← / A | 向左轉 |
| → / D | 向右轉 |
| SPACE | 超級衝刺 (消耗能量) |
| R | 重置遊戲 |

## 如何遊玩

1. 點擊 **START RACE** 按鈕開始比賽
2. 完成 **3圈** 後抵达終點
3. 爭奪 **第1名**！

## 技術細節

- Canvas 2D 渲染
- Catmull-Rom 曲線賽道
- AI對手循跡系統
- 能量管理系統
